# Screenshots
This folder has the screenshots for the Student Finance Tracker project. They show the CodePause dashboard and the Git history of the project.
I added them because CodePause can not export a report, so screenshoots are the way to show its numbers.

Evidence for the CodePause dashboard and the Git history.

- codepause-dashboard.png: CodePause with AI and manual percentages and the session statistics. It has the AI and manual percentages and the session statistics that CodePause recorded while I worked on this project.

- codepause-commands.png: Command Palette search for CodePause commands (there is no report or export command). The command Palette in VS Code (Ctrl + Shift + P) after typing "CodePause". It lists every CodePause command that is available

- git-log.png: output of git log --oneline in the terminal. It lists all the commits of the project, with the newest one at the top.

- github-commits.png: the commits page on Github. It shows the same history as the terminal, with the date and the author of every commit.
The page shows the author (me) of the commits, so it can be checked. It also shows that the work was done over several days and not in one commit.
